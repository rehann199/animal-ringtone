# Privacy and Source

## What this repository is

A portfolio showcase for a production application. It describes the engineering of Animal Ringtone; it is not a source distribution.

## What is published

- Written descriptions of architecture, design decisions and trade-offs
- Original diagrams created for this showcase
- Real screenshots from the Android app
- The app icon, resized

## What is intentionally not published

- Production source code, in whole or in part, including the mobile app and the backend
- Build and signing configuration, certificates and keystores
- Firebase and Google service configuration, API keys, tokens and service-account material
- Ad network identifiers, placement IDs and account details
- Billing product IDs
- Cloud resource names, bucket names and internal endpoints
- Security-rule contents
- Version control history of the production repository
- User data of any kind

## How the descriptions were produced

The production project was inspected read-only. Statements describe behaviour observed in code, manifests and project documents. Where behaviour could not be confirmed it is worded conservatively or left out. Diagram labels are conceptual and do not match production identifiers.

## Images

Screenshots are real captures from the Android app. Android system status bars were removed. Screenshots showing personal account details, other users' names or development-only ad placeholders were not used. Images were re-encoded with metadata removed.

## Publication checks

Before publishing, every file was checked for source code, credentials, signing material, personal data, personal email addresses, local file-system paths, previous account references and embedded image metadata. None remain.

## Access

Source access for hiring or due-diligence purposes can be discussed at the owner's discretion.
